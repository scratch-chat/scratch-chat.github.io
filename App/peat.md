# Scratch チャット

白を基調にした、WebSocketによるリアルタイムチャットです。メッセージ入力欄の上で5色から吹き出しの色を選び、黒文字でメッセージを送信できます。画像と動画の送信、メッセージへの返信、ハート・星のリアクションにも対応しています。参加者数と直近100件のメッセージを表示します。最後の参加者が退出すると、部屋と履歴は即時に削除されます。参加者がいる部屋は最後のコメントから24時間後に解散・削除され、コメントがない場合は作成から24時間後に削除されます。参加者は自分のメッセージを削除でき、管理者操作は認証なしでそのまま使えます。投稿者の識別にはブラウザー内に保存するランダムなトークンを使い、他の参加者には共有しません。

## 画像・動画の送信

入力欄の「画像・動画」からファイルを選択すると送信されます。画像は20MB以下、動画は300MB以下かつ15分以内です。対応形式はJPEG、PNG、GIF、WebP、AVIF画像と、MP4、WebM、QuickTime動画です。動画の長さはブラウザーで読み取って送信前に確認します。アップロードされたファイルはサーバーの`uploads/`に保存され、メッセージ削除、履歴の全削除、または履歴上限を超えた場合に関連ファイルも削除されます。

## 起動方法

```sh
npm start
```

ブラウザーで `http://localhost:8000` を開きます。別のブラウザーや端末から同じURLにアクセスすると、参加者同士でリアルタイムに会話できます。

`PORT` 環境変数で待受ポートを変更できます。
最後のコメントからの削除時間は`ROOM_INACTIVITY_TIMEOUT_MS`環境変数でミリ秒単位に変更できます。既定値は24時間です。
WebSocketライブラリ`ws` 8.23.0は、MITライセンス表記を含めて`vendor/ws.cjs`に単一ファイルでまとめています。外部npm依存はありません。

## GitHub Pages

フロントエンドは [https://scratch-chat.github.io/](https://scratch-chat.github.io/) で公開し、`main`へのpush時にGitHub Actionsから`public/`をデプロイします。HTML、CSS、ブラウザー側JavaScript、画像は`public/index.html`にまとめています。GitHub Pagesは静的ファイルのみを配信するため、リアルタイムチャットとメディアアップロードには別途HTTP/WebSocketサーバーが必要です。接続先は`public/index.html`内の`window.CHAT_WEBSOCKET_URL`で設定します。現在はCodespacesのポート8000を接続先にしています。Codespaceが停止するとチャットも利用できなくなるため、常時利用には常時稼働するWebSocketホストが必要です。

## Codespacesの自動停止を遅らせる

Codespacesのアイドルタイムアウトは、[GitHubのCodespaces設定](https://github.com/settings/codespaces)にある「Default idle timeout」で変更できます。5分から最大4時間まで設定でき、変更は新しく作成するCodespaceに適用されます。今使っているCodespaceには反映されないため、適用するには新しいCodespaceを作成してください。組織のポリシーでより短い時間に制限されている場合は、その制限が優先されます。

Codespaceはアイドル状態でなくても最大12時間で停止します。また、稼働中は利用していなくても課金されます。ポートへのアクセスだけでは停止タイマーをリセットできない場合があるため、これは一時的な延長策です。チャットを常時利用するには、Codespacesではなく常時稼働するWebSocketホストが必要です。

## 作成者専用コマンド

部屋を作成したとき、作成者にだけ管理コマンド用のアルファベット2文字が一度表示されます。`Space` キーを押しながら `6780` の後に表示された2文字を入力すると、その部屋のロック画面の表示／解除を切り替えます。

同じく `Space` キーを押しながら `8880` と表示された2文字を続けて入力すると、チャット履歴を全削除してロックを解除します。操作はサーバー側でも部屋作成者と2文字を照合し、他の参加者からは実行できません。ロック状態はサーバーの稼働中のみ保持され、再起動すると解除されます。このロック画面は表示上の制御であり、チャットのデータやWebSocket接続へのアクセス制御ではありません。

作成者向けコマンドバーの「解散」を押すと確認後、全参加者を退出させて履歴を削除し、部屋番号を即時に再利用可能にします。
