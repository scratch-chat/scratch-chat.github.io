# Scratch チャット

白を基調にした、WebSocketによるリアルタイムチャットです。メッセージ入力欄の上で5色から吹き出しの色を選び、黒文字でメッセージを送信できます。画像と動画の送信、メッセージへの返信、ハート・星のリアクションにも対応しています。参加者数と直近100件のメッセージを表示します。参加者は自分のメッセージを削除でき、管理者操作は認証なしでそのまま使えます。投稿者の識別にはブラウザー内に保存するランダムなトークンを使い、他の参加者には共有しません。

## 画像・動画の送信

入力欄の「画像・動画」からファイルを選択すると送信されます。画像は20MB以下、動画は300MB以下かつ15分以内です。対応形式はJPEG、PNG、GIF、WebP、AVIF画像と、MP4、WebM、QuickTime動画です。動画の長さはブラウザーで読み取って送信前に確認します。アップロードされたファイルはサーバーの`uploads/`に保存され、メッセージ削除、履歴の全削除、または履歴上限を超えた場合に関連ファイルも削除されます。

## 起動方法

```sh
npm start
```

ブラウザーで `http://localhost:8000` を開きます。別のブラウザーや端末から同じURLにアクセスすると、参加者同士でリアルタイムに会話できます。

`PORT` 環境変数で待受ポートを変更できます。
WebSocketライブラリ`ws` 8.23.0は、MITライセンス表記を含めて`vendor/ws.cjs`に単一ファイルでまとめています。外部npm依存はありません。

## GitHub Pages

フロントエンドは [https://scratch-chat.github.io/](https://scratch-chat.github.io/) で公開し、`main`へのpush時にGitHub Actionsから`public/`をデプロイします。HTML、CSS、ブラウザー側JavaScript、画像は`public/index.html`にまとめています。GitHub Pagesは静的ファイルのみを配信するため、リアルタイムチャットとメディアアップロードには別途HTTP/WebSocketサーバーが必要です。接続先は`public/index.html`内の`window.CHAT_WEBSOCKET_URL`で設定します。現在はCodespacesのポート8000を接続先にしています。Codespaceが停止するとチャットも利用できなくなるため、常時利用には常時稼働するWebSocketホストが必要です。

## 4桁コマンド

`Space` キーが押されている間だけ、`6` → `7` → `8` → `0` を順番に入力すると全参加者のロック画面の表示／解除を切り替えます。

同じく `Space` キーが押されている間に `8` → `8` → `8` → `0` を順に押すと、チャット履歴を全削除してロックを解除します。サーバープロセス自体は再起動せず、サーバー内のチャット状態を初期化します。

このアプリは認証なしで管理者機能を使えるように設定しています。そのため `ADMIN_ALLOWED_IP` などのIP制限は使わず、誰でもロック、全削除、初期化操作を行えます。ロック状態はサーバーの稼働中のみ保持され、再起動すると解除されます。このロック画面は表示上の制御であり、チャットのデータやWebSocket接続へのアクセス制御ではありません。
