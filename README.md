# このリポジトリの説明
このリポジトリは、プログラミング言語サイトScratch用のリアルタイムで使えるWebsocket型のチャットアプリです。主にAppでこのアプリが動いており、Appを消すと空のリポジトリになりますので十分ご注意ください。
アプリを開くと参加コードの入力画面が表示されます。コードは01〜50で、「部屋を作成」を押すと空いている番号が割り当てられます。同じコードを入力した人同士が同じチャットルームに参加します。最後の参加者が退出すると部屋と履歴が即時に削除され、番号が再利用可能になります。参加者がいる部屋は最後のコメントから24時間後に解散・削除され、コメントがない場合は作成から24時間後に削除されます。
部屋作成者には、作成直後だけ管理コマンド用のアルファベット2文字が表示されます。Spaceキーを押しながら`6780`とその2文字を入力するとロックを切り替え、`8880`とその2文字を入力すると履歴を削除してロックを解除します。これらの操作は部屋作成者だけが実行できます。「解散」を押すと確認後、参加者全員が退出し、履歴を削除して部屋番号をすぐに解放します。
