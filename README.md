# このリポジトリの説明
このリポジトリは、Scratch用のリアルタイムで使えるWebsocket型のチャットアプリです。主にAppでこのアプリが動いており、Appを消すと空のリポジトリになりますので十分ご注意ください。
# 引用方法
① 画面中央部分にある「Code」を押します。
　　![alt text](image.png)
② メニュー一番下の「download zip」を押します。
　　![alt text](image-1.png)
③ そして自分のgithubページを開き、リポジトリを作成します。ファイルアップロードでappの中のファイルをアップロードしてください。またActionsやPagesの設定は別途各自で行う必要がございますのでご注意ください。
